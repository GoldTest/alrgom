# 工资计算器与本地薪资记录工具 - 方案调研与设计

## 一、 项目背景与核心诉求
1. **核心场景**：个人月度工资记录、实发工资反推/正算、年度个税累计预扣计算、历史薪资台账统计与趋势分析。
2. **纯本地隐私保护**：工资属于高度敏感的个人财务隐私数据，必须纯前端运行，所有数据保存在用户浏览器本地，绝不经过第三方服务器。
3. **即开即用**：采用类似 `price-calculator` 的纯单文件网页端（HTML + CSS + JS），无需安装任何运行环境，双击即可直接使用。

---

## 二、 核心核算模型与计算方案调研

中国现行（自2019年实施的《新个人所得税法》）工资计算遵循**“累计预扣法”**与**“社会保险法”**，具体包含以下几大核算模块：

### 1. 五险一金核算模型
五险一金通常以员工上年度月平均工资作为**缴费基数**，并受当地统计部门公布的“社平工资上下限（通常为 60% ~ 300%）”约束。

* **个人缴费常见比例**：
  * **养老保险**：个人缴纳 8%
  * **医疗保险**：个人缴纳 2% + 几元到十几元不等的大病互助金
  * **失业保险**：个人缴纳 0.5%（部分地区为 0.2%~1%）
  * **工伤保险 / 生育保险**：个人不缴费，全部由企业承担
  * **住房公积金**：个人缴纳 5% ~ 12%（企业与个人等比例）
* **补充公积金**（可选）：部分企业有补充公积金，个人额外缴纳 1% ~ 8%。

**计算公式**：
$$\text{个人社保公积金扣除} = \text{社保基数} \times (\text{养老\%} + \text{医疗\%} + \text{失业\%}) + \text{大病医保} + \text{公积金基数} \times \text{公积金\%}$$

---

### 2. 个人所得税（累计预扣法）计算方案
中国大陆工薪个税自2019年起采用**“按年累计、按月预扣”**制度。因此，计算某月的个税不能单独只看当月，而必须结合**当年截至当月的累计数据**。

#### (1) 当月累计应纳税所得额公式
$$\text{累计应纳税所得额} = \sum_{i=1}^{M} \text{税前应发工资}_i - P \times 5000 - \sum_{i=1}^{M} \text{社保公积金}_i - \sum_{i=1}^{M} \text{专项附加扣除}_i - \sum_{i=1}^{M} \text{其他依法扣除}_i$$
*(其中 $P$ 为当前税款所属期申报累计期数。实务中若采用“次月申报制”或包含上年12月发薪结转，第 $M$ 月对应的累计减除期数为 $M+1$，例如6月累计减除3.5万、7月4万、8月4.5万)*

#### (2) 年度累计个税预扣率表（综合所得）
| 级数 | 全年累计应纳税所得额级距 | 预扣率 | 速算扣除数 |
| :--- | :--- | :--- | :--- |
| 1 | 不超过 36,000 元的部分 | 3% | 0 |
| 2 | 超过 36,000 元至 144,000 元的部分 | 10% | 2,520 |
| 3 | 超过 144,000 元至 300,000 元的部分 | 20% | 16,920 |
| 4 | 超过 300,000 元至 420,000 元的部分 | 25% | 31,920 |
| 5 | 超过 420,000 元至 660,000 元的部分 | 30% | 52,920 |
| 6 | 超过 660,000 元至 960,000 元的部分 | 35% | 85,920 |
| 7 | 超过 960,000 元的部分 | 45% | 181,920 |

> 💡 **跳档现象说明**：当个人累计应纳税所得额跨越 **144,000 元** 临界线时，税率将从 10% 瞬间翻倍至 20%，超过部分将按 20% 征收，当月扣税额将出现明显的“台阶式激增”（如从一千多猛增至三千多），属于累进预扣法的正常税收规律。

#### (3) 当月实际应扣个税
$$\text{当月应扣个税} = (\text{累计应纳税所得额} \times \text{预扣率} - \text{速算扣除数}) - \sum_{i=1}^{M-1} \text{前几月已缴个税}$$
*(若累计应纳税所得额 $\le 0$，则当期应扣税额为 0)*

### 3. 七项专项附加扣除标准
1. **子女教育**：每个子女 2000元/月
2. **继续教育**：学历教育 400元/月，技能证书 3600元/年
3. **住房贷款利息**：1000元/月（最长240个月）
4. **住房租金**：直辖市/省会等大城市 1500元/月，中等城市 1100元/月，小城市 800元/月（与房贷利息二选一）
5. **赡养老人**：独生子女 3000元/月，非独生子女按协议分摊（每人最高不超过1500元）
6. **3岁以下婴幼儿照护**：每个婴幼儿 2000元/月
7. **大病医疗**：个人自付超 15,000 部分，最高 80,000元/年（年度汇算清缴）

### 4. 年终奖核算方案（二选一）
* **方案 A：单独计税（优惠政策）**
  * 用年终奖总额 $\div 12$，查月度税率表确定税率和速算扣除数：
    $$\text{年终奖应纳税额} = \text{年终奖总额} \times \text{适用税率} - \text{速算扣除数}$$
* **方案 B：并入当年综合所得合并计税**

---

### 5. 专属税务系统与年度汇算清缴（多退少补）
* **纳税阶梯与“跳档”预警**：
  * 动态跟踪当年累计应纳税所得额，精准映射 7 级阶梯税率（3%、10%、20%、25%、30%、35%、45%）；
  * 实时预测距离下一档税率跳档差额并提供可视化进度条；
  * 分析提示当月扣税由于“跳档”产生的变化原因。
* **年度综合所得汇算清缴测算（对应个税 APP 3~6月汇算）**：
  * 支持从本地薪资台账一键同步全年工资薪金与已预扣个税；
  * 补充汇总兼职劳务报酬（减除20%费用计入）、稿酬（减除20%后减按70%计入）；
  * 汇总 60,000 元年度基本减除费用、三险一金、专项附加扣除、大病医疗超 15,000 自负补充扣除及个人养老金（最高12,000元抵税）；
  * 精确得出最终【应退税款】或【应补税款】。
* **个人养老金节税效益测算**：
  * 根据用户所在的当前边际税率，计算存满 12,000 元个人养老金当年可直接减少/退税的个税金额。

### 6. 加班工资与特定考勤折算方案
* **工作日加班核算规则**：
  * **起计时间**：每晚 20:30（8点半）开始产生加班费；
  * **起步基础金额**：加到 20:30 计 **36 元**；
  * **延时递增**：后续每多加 1 小时递增 **18 元**（例如：21:30 为 54 元，22:30 为 72 元，23:30 为 90 元，依此类推）。
* **周末加班核算规则（周六、周日）**：
  * **阶梯标准**：每加班满 3 小时计 **25 元**（满 3 小时为 25 元，满 6 小时为 50 元）；
  * **封顶限制**：单日 **75 元封顶**（9小时或全天加班）。
* **法定标准与日薪折算**：
  * **月法定计薪天数**：21.75 天（$[365 - 104 \text{个休息日}] \div 12$）；
  * **日基本工资** = 基本月薪 $\div 21.75$；
  * **小时基本工资** = 日工资 $\div 8$。

## 三、 本地数据存储方案对比与选型

| 维度 | 方案 A：LocalStorage | 方案 B：IndexedDB | 方案 C：File System Access API |
| :--- | :--- | :--- | :--- |
| **存储容量** | 约 5MB ~ 10MB | 几百 MB ~ 几十 GB | 无限制（直接操作本地文件） |
| **开发复杂度** | 极低（同步 API，容易维护） | 中等（异步 Promise 封装） | 较高（需浏览器授权，Firefox/移动端兼容受限） |
| **数据安全性** | 用户清理浏览器缓存可能丢失 | 用户清理浏览器缓存可能丢失 | 真实保存在指定磁盘目录 |
| **性能** | 几千条月度薪资记录读写在 1ms 内 | 极高，适合超大数据量 | 读写依赖本地文件 IO |
| **适用性判断** | 个人薪资记录即使记录30年也仅360条记录，体积 < 500KB，**LocalStorage 性能最优且最为稳定**。 |

### 推荐存储架构策略（双重保障机制）：
1. **实时持久化**：优先使用 `localStorage` 自动无感保存每一次输入与计算结果，页面刷新/关闭永不丢失。
2. **冷备份与跨设备迁移**：
   * **导出功能**：一键导出所有历史记录与配置为标准 `.json` 文件；
   * **导入功能**：支持导入 `.json` 恢复或合并记录；
   * **Excel / CSV 导出**：支持一键导出薪资台账明细，方便自行在 Excel 中存档。

## 四、 核心系统功能架构

1. **📅 1~12月全年薪资纵览大表（核心主屏）**：
   * **全景联动**：一屏展开 1~12 月全景大表，每一行代表一个自然月，支持随时切换年份（如 2026/2025/2027）。
   * **各月独立可配**：每个月份均提供独立的输入框，可自由配置该月的**基本工资、加班费、奖励与餐贴车贴**（已加回独立的“奖励”列，并将补贴精简确认为专属的“餐贴车贴”列）。
   * **内联毫秒级重算**：修改任一格子的数值，整张表格后续月份的**累计应税所得、适用税率档位、当月应扣个税、实发到手工资及年度汇总**全部实时自动重算并持久化保存。
   * **一键填充与初始化**：支持设定基准月薪，一键将底薪批量填充至全年 12 个月。
2. **⚙️ 五险一金全局统一配置**：
   * 统一配置：社保基数、住房公积金基数、公积金缴纳比例（5%~12%）、大病互助医保及七项专项附加扣除。
   * **一次配置，全年生效**：默认统一套用到 1~12 月的各个自然月，无需每月重复填写，修改后一键同步刷新全年。
3. **⏰ 专属加班核算器与月份回填**：
   * 按照专属规则（工作日 20:30 起步 36 元，后续每小时 18 元；周末满 3h 计 25 元，全天 75 元封顶）。
   * 在全年大表任一月份点击 `⚡` 按钮，直接针对该月份核算加班费，一键填入该月单元格。
4. **🏛️ 税务系统与年度汇算清缴**：
   * 阶梯跳档预警看板与纳税进度条，直观反映跨档跳税原因；
   * 年度综合所得汇算清缴测算器（多退少补），精确测算退税或补税金额；
   * 个人养老金 12,000 元抵税额效益分析。
5. **📊 数据管理与本地备份**：
   * 纯前端本地存储（LocalStorage），零网络上传；
   * 支持一键导出标准 `.csv` 全年薪资表格（可在 Excel 中直接打开归档）；
   * 支持一键下载与恢复 `.json` 完整备份文件。
