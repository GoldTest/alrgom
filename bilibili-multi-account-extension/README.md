# B站多账号助手 (Bili Multi-Account Chrome Extension) v1.5

一个基于 **Chrome Extension Manifest V3** 标准开发的高性能、低开销的 B站 多账号并行管理独立浏览器插件。

---

## 🌟 核心功能全景图

### 1. 主账号点赞/取消点赞，副账号全自动静默跟随 (无需弹窗操作)
- **原生操作零感触发**：在 B 站视频播放页（`https://www.bilibili.com/video/BV...`），你只需像平常一样使用主账号给视频点赞或取消点赞（无论是点击原生点赞按钮还是按键盘 `q` 键）；
- **点赞与取消点赞双向同步**：
  - 主号点赞（`like: 1`），副账号全自动跟随点赞；
  - 主号取消点赞（`like: 2`），副账号全自动跟随取消点赞；
- **双重精准感知机制**：
  - **网络层感知**：后台 Service Worker 通过 `chrome.webRequest` 实时捕获点赞与取消点赞网络请求；
  - **DOM 层感知**：Content Script 识别原生点赞按钮高亮状态与快捷键交互双重兜底，对相同动作加入 4 秒防抖去重，避免连击抖动；
- **副账号防风控排队跟随**：后台自动过滤出“除当前主账号以外的所有已启用副账号”，配置随机离散延迟（100ms ~ 400ms）在后台依次执行；
- **非侵入式微交互气泡**：跟随完成后，在网页右下角仅浮现轻量、透明磨砂的胶囊提示（如 `👍 副账号已跟随点赞 (1/1)` 或 `👍 副账号已跟随取消点赞 (1/1)`），2.8秒后自动淡出消失，绝不弹出窗口打断用户观看体验；
- **灵活开关控制**：在扩展设置页中可自由开启/关闭“副账号自动跟随点赞”与“跟随点赞气泡提醒”。

### 2. 直播间智能联动：原生发言自动跟随 + 各账号连接与资产状态看板
- **主号原生发言，副号静默跟随（零感触发）**：
  - 在 B 站直播间原生输入框正常打字并发送弹幕（支持 Enter 发送或点击原生发送按钮）；
  - 后台 Service Worker 通过 `chrome.webRequest` 实时捕获真实直播间号与发言内容；
  - 自动调度其余所有已启用的副账号，按防风控离散延迟（100ms ~ 400ms）在后台依次排队跟随发送该弹幕；
  - 发送完成后，页面右下角浮现微交互轻量胶囊提示（如 `💬 副账号已跟随发言 (1/1)`），无需打开任何控制面板；
- **页面悬浮挂件：账号连接与资产看板 + 全向拖拽调整 + 背包与礼物定时循环赠送**：
  - **悬浮球与控制面板自由拖拽与记忆**：
    - 悬浮球支持鼠标/触摸自由按住拖拽调整到屏幕任意位置，位置自动持久化保存（刷新或切换页面后保持位置不变）；智能区分拖拽与点击，拖拽结束不会误触发展开面板；
    - 展开的悬浮控制面板同样支持按住顶部标题栏自由拖拽调整位置，同样自动持久化记忆；
    - 具备全向视口边界检测与窗口大小自适应保护，无论如何拖拽均绝不超出屏幕可视范围；
  - **礼物与背包支持定时循环送礼 (每 M 秒送 N 个，支持开始 / 停止)**：
    - 直播间礼物列表与背包抽屉均内置 **【⏱️ 定时循环送礼】** 控制控制台；
    - 点击任意礼物行或点击 **【循环】** 按钮即可一键将其设为循环送礼目标；
    - 可灵活配置 **每 M 秒**（自定义间隔）送 **N 个**（每次数量）；
    - 醒目的 **【▶ 开始】** 与 **【⏹ 停止】** 按钮，运行时呈现高亮红色呼吸状态；
    - 实时呈现秒级倒计时与累计送出统计（如 `🟢 运行中: 已送 3次 (共 15个) | 下次: 4秒后`）；
    - 完备的异常保护：当账号电池余额不足、背包道具已送完或网络异常时，将自动平稳停止循环并弹出 Toast 友好提醒，保护账号与余额安全；
  - **背包道具明细展开与赠送**：
    - 点击每个账号上的 **🎒 N件 ▾**，即可就地展开该账号的专属背包道具抽屉；
    - 抽屉清晰列出各个背包道具（如辣条、小心心等）、拥有数量与到期时间；
    - 每个道具配备 **【送1个】**、**【全送】** 及 **【循环】** 按钮，点击即可直接使用该账号向当前直播间主播赠送该免费道具；
    - 赠送成功后实时局部扣减数量并更新看板，伴随轻量 Toast 提示反馈；
  - 点击卡片主体依然支持一秒快捷切换主账号；
  - 支持点击 **【🔄 刷新】** 实时重新同步各账号的电池与背包资产；
- **Popup 独立控制台（备用手动群控）**：
  - 若需要跨房间手动调度或输入指定房间号群发，右上角弹窗的【直播群控】标签页继续完整保留，满足进阶调试需求；
- **独立开关配置**：在扩展设置页中可自由开启或关闭“直播间发言副账号自动跟随”与“跟随发言轻量气泡提醒”。

### 3. 网页端登录自动发现与轮换（无需手机 App 扫码）
- **自动抓取当前登录号**：后台实时监听浏览器 Cookie 变动，只要你在网页上用短信验证码或密码登录，插件后台自动提取用户信息并保存入库，自动设为主号。
- **一键安全登录新号**：点击挂件或弹窗中的 **【➕ 登录新号】**，插件自动备份现有账号，清除当前浏览器 B 站会话并打开登录页。登录新号后自动捕获，实现纯网页端无感多号录入。

### 4. 后台隔离并发与防风控
- 利用 `chrome.declarativeNetRequest.updateSessionRules` 会话规则与异步互斥锁，为各账号装配独立 Cookie 请求通道。
- 内置可调节的随机离散时延（100ms ~ 400ms），防止多账号同一时刻并发导致被系统拦截。

## 📂 项目结构

```text
bilibili-multi-account-extension/
├── manifest.json            # 扩展配置文件 (Manifest V3, 包含 webRequest 与 DNR 权限)
├── background.js            # 后台 Service Worker (webRequest点赞监听/副号跟随调度/自动切号/防风控互斥)
├── icons/                   # 插件图标 (16x16, 48x48, 128x128)
├── lib/
│   └── qrcode.js            # 纯原生离线二维码渲染库 (备用扫码)
├── utils/
│   ├── storage.js           # chrome.storage 账号与偏好设置持久化模块
│   └── bili-api.js          # B站核心接口封装 (直播间解析/弹幕/免费送礼/视频点赞/用户信息)
├── content/
│   └── content.js           # 网页 Shadow DOM 悬浮控制挂件 (原生点赞事件感知/轻量胶囊提醒/切号/直播群发)
└── popup/
    ├── popup.html           # 扩展右上角弹窗控制台 (账号管理/直播群控/跟随点赞设置)
    ├── popup.css            # 精致粉白样式表
    └── popup.js             # 弹窗控制器逻辑
```

## 🚀 极速上手使用指引

### 1. 加载 / 更新插件
1. 打开 Chrome 或 Edge，访问 `chrome://extensions/`（Edge 访问 `edge://extensions/`）；
2. 开启右上角 **【开发者模式】**；
3. 点击 **【加载已解压的扩展程序】**，选择插件目录：
   ```
   D:\Develop\alrgom\bilibili-multi-account-extension
   ```
   *(如果之前已加载过，直接点击卡片右下角的 🔄 重新加载图标即可更新至最新版本)*。

### 2. 多账号录入（无需手机）
1. 在浏览器中打开 `https://www.bilibili.com`，正常登录你的 **账号 A**；
2. 页面右下角悬浮球点击展开，底部点击 **【🔄 同步当前号】**，账号 A 录入成功并标记为主号；
3. 点击 **【➕ 登录新号】**，页面会自动清除登录态并打开登录页，使用短信/密码登录你的 **账号 B**；
4. 登录完成后，账号 B 被全自动识别入库！此时悬浮面板中即可在账号 A 和账号 B 之间任意一秒切换。

### 3. 主号点赞，副号自动跟随
1. 确保已有 2 个或以上账号处于启用状态；
2. 正常打开任意 B 站视频播放页面；
3. 使用主账号点击视频下方的原生点赞按钮（或按键盘 `q` 键）；
4. 插件将在后台静默调度其它副账号依次跟随点赞，并在页面右下角轻量提示完成状态，无需打开任何弹窗！

### 4. 直播间多账号同时发言与送礼
1. 打开任意 B 站直播间（如 `https://live.bilibili.com/6`）；
2. 点击悬浮球，面板自动切换为“直播间快捷同发”区域；
3. 点击预设的 **666** 标签或在输入框中打字点击 **【全发】**，各账号将按防风控间隔在公屏完成发言；
4. 点击 **【🎁 全号送小心心】**，所有账号将自动送出免费心意礼物，并在页面弹出实时结果反馈。
