# B站多账号助手 (Bili Multi-Account Chrome Extension) v1.4

一个基于 **Chrome Extension Manifest V3** 标准开发的高性能、低开销的 B站 多账号并行管理独立浏览器插件。

---

## 🌟 核心功能全景图

### 1. 网页内嵌智能悬浮小挂件（根据页面自适应）
- **Shadow DOM 纯粹隔离**：无论 B 站页面如何升级改版，悬浮小挂件样式独立沙箱隔离，绝不影响网页原有布局。
- **页面内一秒切号**：在 B 站任意页面，点击右下角悬浮球展开，直观展示所有账号头像，**点击任意头像瞬间切换主账号并自动刷新网页**。
- **视频播放页（www.bilibili.com/video/BV...）智能联动**：
  - 自动识别当前正在播放的稿件 BV 号；
  - 挂件面板提供 **【👍 全号点赞】** 与 **【⚡ 全号三连 (点赞+投币+收藏)】**；
  - 点击后，后台自动调度所有已启用的账号按防风控随机间隔依次执行，并在页面弹出实时完成反馈。
- **直播间（live.bilibili.com/...）智能联动**：
  - 自动解析直播间房间号与主播 UID；
  - 内置常用高频弹幕标签（`666`、`哈哈哈`、`打卡`、`好听`、`太强了` 等），点击即可多账号群发；
  - **免费礼物群控打赏**：提供 **【🎁 全号送小心心】**，优先为每个账号送出背包内的免费道具或小心心（安全仅限免费礼物，绝不扣费）。

### 2. 网页端登录自动发现与轮换（无需手机 App 扫码）
- **自动抓取当前登录号**：后台实时监听浏览器 Cookie 变动，只要你在网页上用短信验证码或密码登录，插件后台自动提取用户信息并保存入库，自动设为主号。
- **一键安全登录新号**：点击挂件或弹窗中的 **【➕ 登录新号】**，插件自动备份现有账号，清除当前浏览器 B 站会话并打开登录页。登录新号后自动捕获，实现纯网页端无感多号录入。

### 3. 后台隔离并发与防风控
- 利用 `chrome.declarativeNetRequest.updateSessionRules` 会话规则与异步互斥锁，为各账号装配独立 Cookie 请求通道。
- 内置可调节的随机离散时延（500ms ~ 1500ms），防止多账号同一时刻并发导致被系统吞弹幕或拦截。

## 📂 项目结构

```text
bili-multi-account/
├── manifest.json            # 扩展配置文件 (Manifest V3)
├── background.js            # 后台 Service Worker (Cookie监听/自动发现/DNR规则/主号切换/视频互动/弹幕调度/送礼调度)
├── icons/                   # 插件图标 (16x16, 48x48, 128x128)
├── lib/
│   └── qrcode.js            # 纯原生离线二维码渲染库 (备用扫码)
├── utils/
│   ├── storage.js           # chrome.storage 账号状态持久化模块
│   └── bili-api.js          # B站核心接口封装 (直播间解析/弹幕/免费送礼/视频点赞三连/用户信息)
├── content/
│   └── content.js           # 网页 Shadow DOM 悬浮控制挂件 (自适应视频点赞三连/直播群发与送礼/切号)
└── popup/
    ├── popup.html           # 扩展右上角弹窗控制台
    ├── popup.css            # 精致粉白样式表
    └── popup.js             # 弹窗控制器逻辑
```

## 🚀 极速上手使用指引

### 1. 加载 / 更新插件
1. 打开 Chrome 或 Edge，访问 `chrome://extensions/`（Edge 访问 `edge://extensions/`）；
2. 开启右上角 **【开发者模式】**；
3. 点击 **【加载已解压的扩展程序】**，选择插件目录：
   ```
   /data/dsh/home/plugins/bili-multi-account
   ```
   *(如果之前已加载过，直接点击卡片右下角的 🔄 重新加载图标即可更新至最新版本)*。

### 2. 多账号录入（无需手机）
1. 在浏览器中打开 `https://www.bilibili.com`，正常登录你的 **账号 A**；
2. 页面右下角悬浮球点击展开，底部点击 **【🔄 同步当前号】**，账号 A 录入成功并标记为主号；
3. 点击 **【➕ 登录新号】**，页面会自动清除登录态并打开登录页，使用短信/密码登录你的 **账号 B**；
4. 登录完成后，账号 B 被全自动识别入库！此时悬浮面板中即可在账号 A 和账号 B 之间任意一秒切换。

### 3. 视频一键全号点赞与三连
1. 打开任意 B 站视频（如 `https://www.bilibili.com/video/BV...`）；
2. 点击页面右下角的粉色 **B** 悬浮球；
3. 面板自动呈现“当前视频群控”区域，点击 **【👍 全号点赞】** 或 **【⚡ 全号三连】**；
4. 插件将自动调度所有已启用的账号在后台依次完成点赞/投币/收藏！

### 4. 直播间多账号同时发言与送礼
1. 打开任意 B 站直播间（如 `https://live.bilibili.com/6`）；
2. 点击悬浮球，面板自动切换为“直播间快捷同发”区域；
3. 点击预设的 **666** 标签或在输入框中打字点击 **【全发】**，各账号将按防风控间隔在公屏完成发言；
4. 点击 **【🎁 全号送小心心】**，所有账号将自动送出免费心意礼物，并在页面弹出实时结果反馈。
