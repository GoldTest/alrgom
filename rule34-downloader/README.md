# Rule34.world 高级下载助手 (Rule34 World Downloader Pro)

专为 [rule34.world](https://rule34.world/) 打造的油猴脚本（Tampermonkey / Violentmonkey 用户脚本）。提供**Tag多页全量批量下载（带实时明细列表）**、**右侧专属悬浮多功能工具栏**（包含下载管理器面板、Tag批量面板、偏好配置面板）、**99%满载看门狗自愈防卡死**、**本地任意真实文件夹选择**、网格卡片一键下载、二级详情页下载、实时下载进度与下载状态持久化防重复下载。

---

## 🌟 核心功能面板与特性

### 1. ⚡ Tag 全量多页批量下载面板（带实时动态任务列表）
- **自动识别当前 Tag 页面**：在 Tag 列表页（如 `/rwt4184`、`/overwatch` 等）自动显示 **「⚡ 批量下载此 Tag」** 胶囊按钮。
- **全量多页自动翻页**：通过底层 Post Search API 全量自动爬取该 Tag 下的全部多页作品。
- **📋 实时明细任务列表（v1.5.0 新增）**：
  - 在批量面板内直接实时展示每篇作品明细：Post ID（可点击跳转）、类型（`VIDEO`/`IMAGE`）、文件名、状态标签。
  - 动态状态呈现：`🚀 下载中 45%`、`✅ 已完成`、`⏭️ 已跳过`、`⏳ 排队中`、`❌ 失败`。
  - **分类 Tab 切换**：一键按 `全部`、`下载中`、`已完成`、`已跳过`、`失败` 筛选查看。
- **智能去重过滤**：默认自动跳过本地已下载过的作品，仅下载新内容。
- **多并发平滑队列**：1~6 线程并发，自动排队下载，避免触发 CDN 限流。

---

### 2. 🛸 右侧多功能悬浮工具条 (Floating Dock)
在页面右下角常驻 3 个模块化悬浮球按钮：
- **📥 下载任务管理器 (Downloads Panel)**：
  - 查看当前正在进行的下载任务，显示每个作品的 Post ID、类型、文件名及**实时动态进度条与百分比**。
  - 悬浮球右上角自带正在下载任务数的**呼吸气泡徽标**（如显示 `3`）。
- **⚡ 批量多页下载面板 (Batch Download Panel)**：
  - 独立的 Tag 批量下载控制台与实时任务明细列表。
- **⚙️ 偏好设置面板 (Settings Panel)**：
  - 本地任意真实文件夹绑定（File System Access API）与重置。
  - 分类子目录规则与快捷预设模板（如 `{artist}`, `{copyright}`, `{type}` 等）。
  - 文件名命名模板与画质/编码偏好。

---

### 3. 🛡️ 99% / 100% 满载看门狗自愈（防假死）
- 当字节传输完毕时，启动 2 秒看门狗，若浏览器/扩展未决议 `onload`，主动判定完成并自愈存盘。
- 本地文件系统 `writable.close()` 超时保护与 20 秒全局心跳巡检，彻底杜绝任务卡在 99% 不动。

---

### 4. 📁 原生本地保存文件夹选择（突破浏览器限制）
- 接入现代浏览器 **File System Access API**：点击 **“📁 选择文件夹”**，可直接选择你硬盘上的任意位置（如 `D:\Images\Rule34`）。
- 选定后通过 IndexedDB 持久化记住授权，下载时直接流式保存到本地该专属目录。

---

### 5. 🖼️ 一级网格与二级详情页下载
- **网格卡片右下角一键下载**：在首页、搜索页、热门榜等各页面的卡片右下角添加半透明毛玻璃下载按钮。
- **二级详情页操作栏无缝集成**：在详情页（`/post/:id`）的操作栏前自动挂载原画下载按钮。
- **双向实时同步与持久化**：刷新页面或多标签页切换，已下载状态永不丢失。

---

## 📦 安装与使用

1. 在浏览器中安装 **Tampermonkey（篡改猴）** 或 **Violentmonkey（暴力猴）** 扩展。
2. 打开 Tampermonkey 管理面板 -> 点击 **“+ 添加新脚本”**。
3. 将本项目文件夹下的 [`rule34-world-downloader.user.js`](./rule34-world-downloader.user.js) 全部内容复制并粘贴到编辑器中。
4. 按 `Ctrl + S` 保存脚本。
5. 打开 [https://rule34.world/rwt4184](https://rule34.world/rwt4184)，点击页面顶部的 **“批量下载 #rwt4184”** 或右下角悬浮球，即可一键全量批量下载并实时查看明细任务列表！
