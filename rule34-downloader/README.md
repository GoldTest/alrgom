# Rule34.world 高级下载助手 (Rule34 World Downloader Pro)

专为 [rule34.world](https://rule34.world/) 打造的油猴脚本（Tampermonkey / Violentmonkey 用户脚本）。提供**同 Tag 多页全量批量下载**、**本地任意真实文件夹选择**、网格卡片一键下载、二级详情页下载、实时下载进度、下载状态持久化防重复下载、多标签页状态实时同步与悬浮配置面板。

---

## 🌟 核心功能特性

1. **⚡ 同 Tag 多页全量批量下载（如 `https://rule34.world/rwt4184`）**
   - **自动识别当前 Tag 页面**：在 Tag 列表页（如 `/rwt4184`、`/overwatch`、`/zenless_zone_zero` 等）自动显示 **「⚡ 批量下载此 Tag」** 专属按钮。
   - **自动跨多页遍历抓取**：通过底层 Post Search API（游标 Pagination）全量自动爬取该 Tag 下的全部多页作品。
   - **智能去重过滤**：默认自动跳过本地已下载过的作品，仅下载新作品，不消耗多余流量。
   - **多并发平滑队列**：支持自定义并发数（1~6 线程并发），自动队列调度，避免触发 CDN 频控。
   - **媒体类型过滤**：支持选择“全部”、“仅视频 (MP4)”、“仅图片 (JPG/AVIF)”。
   - **实时统计与进度面板**：直观展示总作品数、成功数、跳过数、失败数、百分比进度条，支持随时暂停/继续/终止。
   - **全局入口**：在右下角悬浮球与设置菜单中也可直接输入任何想要下载的 Tag 名称一键启动！

2. **📁 原生本地保存文件夹选择（突破浏览器限制）**
   - 接入现代浏览器 **File System Access API**：点击悬浮面板中的 **“📁 选择文件夹”**，可直接选择你硬盘上的任意位置（如 `D:\Images\Rule34` 或 `E:\Collections\R34`）。
   - 选定后通过 IndexedDB 持久化记住授权，下载时直接流式保存到本地该专属目录。
   - 若未选择或浏览器不支持，自动平滑兼容为默认下载目录。

3. **📂 智能分类子目录与快捷预设**
   - 提供了快捷预设下拉菜单与自定义变量：
     - `Rule34World/{artist}`（按画师分类分目录）
     - `Rule34World/{copyright}`（按原作作品分类）
     - `Rule34World/{character}`（按角色分类）
     - `Rule34World/{type}`（按图片/视频分类）
     - `Rule34World/{date}`（按发布日期分类）
     - `Rule34World`（平铺直存）

4. **一级网格卡片右下角一键下载**
   - 在首页、搜索页、热门榜（Hot）、高分榜（Highest）、合集（Playlists）、趋势（Trends）等页面的每一个作品卡片右下角添加半透明磨砂质感的下载按钮。
   - 点击直接解析原画/原视频下载，绝不遮挡或阻碍正常浏览。

5. **实时下载进度显示**
   - 解析中显示旋转加载动效。
   - 下载中动态显示百分比进度（如 `45%`），直观掌控视频或高清大图下载进度。
   - 完成后转为绿色已下载状态标记（`✓`）。

6. **二级详情页无缝集成与状态同步**
   - 进入帖子详情页（`/post/:id`）时，在操作栏（点赞、收藏栏）前自动挂载“下载原画 / 下载中 / 已下载”操作按钮，风格与原生主题完美融合。
   - 一级列表页与二级详情页下载状态**双向实时同步**，多标签页跨页面同步。

7. **下载状态持久化与防重复下载**
   - 下载记录通过 Tampermonkey 独立存储空间持久化保存，**刷新页面、关闭浏览器后下载状态永不丢失**。
   - 智能防重复机制：已下载的项目会展示绿色状态；再次点击时支持**弹窗确认、自动跳过或直接重新下载**（可在设置中配置）。

8. **全方位画质与命名定制**
   - **文件名模板自由定制**：支持 `{id}`, `{artist}`, `{character}`, `{copyright}`, `{tags}`, `{resolution}`, `{type}`, `{date}`。
   - **画质保障**：
     - 图片：原画 JPG (`pic.jpg` / `raw`) / 高效 AVIF (`picavif.avif`)。
     - 视频：最高画质 (1080p / 原画) / 高清 (720p) / 流畅 (480p) / 原版压制，以及编码偏好（H.264 MP4 / AV1 / HEVC）。
   - **元数据导出**：支持同时导出全量 Tag 与属性的 `.json` 文件。

## 📦 安装方法

1. 在浏览器中安装 **Tampermonkey（篡改猴）** 或 **Violentmonkey（暴力猴）** 扩展。
2. 打开 Tampermonkey 管理面板 -> 点击 **“+ 添加新脚本”**。
3. 将本项目文件夹下的 [`rule34-world-downloader.user.js`](./rule34-world-downloader.user.js) 全部内容复制并粘贴到编辑器中。
4. 按 `Ctrl + S` 保存脚本。
5. 打开 [https://rule34.world/rwt4184](https://rule34.world/rwt4184)，点击页面顶部的 **“批量下载 #rwt4184”** 或右下角悬浮球，即可一键全量批量下载多页内容！
