# Rule34.world 高级下载助手 (Rule34 World Downloader Pro)

专为 [rule34.world](https://rule34.world/) 打造的油猴脚本（Tampermonkey / Violentmonkey 用户脚本）。提供**右侧专属悬浮多功能工具栏**（包含下载管理器面板、Tag多页全量批量下载面板、偏好配置面板）、**本地任意真实文件夹选择**、网格卡片一键下载、二级详情页下载、实时下载进度、下载状态持久化防重复下载与跨标签页实时同步。

---

## 🌟 核心功能面板与特性

### 1. 🛸 右侧多功能悬浮工具条 (Floating Dock)
在页面右下角常驻 3 个模块化悬浮球按钮：
- **📥 下载任务管理器 (Downloads Panel)**：
  - 查看当前正在进行的所有下载任务列表，显示每个作品的 Post ID、类型（图片/视频）、文件名及**实时动态进度条与百分比**。
  - 显示最近下载完成的 15 篇历史记录及时间戳，可直达帖子页面。
  - 悬浮球上自带**正在下载任务数呼吸气泡徽标**（如显示 `3`），一眼掌握后台下载状况。
- **⚡ 批量多页下载面板 (Batch Download Panel)**：
  - 独立的 Tag 批量下载控制台，支持指定任意 Tag（或自动识别当前 Tag 页面如 `/rwt4184`）。
  - 自由设定媒体类型（全部 / 仅视频 / 仅图片）、并发线程数（1~6）、最大扫描页数。
  - 实时显示：发现总数、成功数、跳过数、失败数、百分比进度条与暂停/终止控制。
- **⚙️ 偏好设置面板 (Settings Panel)**：
  - 本地任意真实文件夹绑定（File System Access API）与重置。
  - 分类子目录规则与快捷预设模板（如 `{artist}`, `{copyright}`, `{type}` 等）。
  - 文件名命名模板与占位符标签快速插入。
  - 画质与视频编码偏好、防重复下载策略、元数据 JSON 导出与系统通知开关。

---

### 2. ⚡ 同 Tag 多页全量批量下载
- **自动识别当前 Tag 页面**：在 Tag 列表页（如 `/rwt4184`、`/overwatch` 等）自动显示 **「⚡ 批量下载此 Tag」** 胶囊按钮。
- **游标自动翻页抓取**：通过底层 Post Search API 全量自动爬取该 Tag 下的全部多页作品。
- **智能去重过滤**：默认跳过本地已下载过的作品，仅下载新更新内容。
- **多并发平滑队列**：1~6 线程并发，自动排队下载，避免触发 CDN 限流。

---

### 3. 📁 原生本地保存文件夹选择（突破浏览器限制）
- 接入现代浏览器 **File System Access API**：点击 **“📁 选择文件夹”**，可直接选择你硬盘上的任意位置（如 `D:\Images\Rule34`）。
- 选定后通过 IndexedDB 持久化记住授权，下载时直接流式保存到本地该专属目录。

---

### 4. 🖼️ 一级网格与二级详情页下载
- **网格卡片右下角一键下载**：在首页、搜索页、热门榜、合集等各页面的卡片右下角添加半透明毛玻璃下载按钮。
- **二级详情页操作栏无缝集成**：在详情页（`/post/:id`）的操作栏前自动挂载原画下载按钮。
- **实时下载进度显示**：旋转加载动效 ➔ 实时动态百分比（如 `45%`）➔ 绿色已下载标记（`✓`）。
- **双向实时同步与持久化**：刷新页面或多标签页切换，已下载状态永不丢失。

---

## 📦 安装与使用

1. 在浏览器中安装 **Tampermonkey（篡改猴）** 或 **Violentmonkey（暴力猴）** 扩展。
2. 打开 Tampermonkey 管理面板 -> 点击 **“+ 添加新脚本”**。
3. 将本项目文件夹下的 [`rule34-world-downloader.user.js`](./rule34-world-downloader.user.js) 全部内容复制并粘贴到编辑器中。
4. 按 `Ctrl + S` 保存脚本。
5. 打开 [https://rule34.world/](https://rule34.world/)，点击右下角的 3 个悬浮按钮即可分别开启**下载任务面板**、**批量下载面板**与**设置面板**！
