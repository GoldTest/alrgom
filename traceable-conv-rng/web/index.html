基于卷积与池化的可追溯 PRNG 核心架构

1. 为什么卷积与池化可以实现确定性伪随机数？

传统 PRNG（如 Xorshift、LCG）多为标量串行递推。而基于 2D 矩阵前向传播的算法，只需确定**初始种子矩阵 $L_0$** 与 **卷积核参数 $K_1, K_2$**，即可在有限整数字长域（$\mathbb{Z}_{2^{32}}$）内完成严格可再现、可并发的确定性映射。

2. 核心网络层结构 (Pipeline Layers)

  • Layer 0 (种子哈希扩展): 使用 SplitMix64 散列函数将 64 位 Seed 扩展为 $N \times N$ 矩阵。
  • Layer 1 (3x3 ARX 卷积): 引入 **Add-Rotate-XOR (ARX)** 非线性代数特征核。通过循环移位与大素数乘法打破线性叠加，提供强雪崩效应。
  • Layer 2 (2x2 XOR 异或池化): 解决传统 Max Pooling（偏向最大值）或 Average Pooling（趋近正态分布）导致均匀性失真的问题。采用 $2 \times 2$ 步长下采样的位异或池化，完美保留均匀比特熵。
  • Layer 3 (3x3 扩散卷积): 进行第二次空间邻域非线性混合，消除周期性模式，生成最终伪随机数流。

3. 可追溯性 (Traceability & Lineage Graph)

每个输出节点 $L_3[r,c]$ 的感受野（Receptive Field）在网络拓扑结构中是精确且确定可计数的。 算法支持通过有向无环图（DAG）逐级反向追踪该随机数受哪些卷积权重、感受野像素块影响，直至归因于种子矩阵 $L_0$ 中的原始比特。
