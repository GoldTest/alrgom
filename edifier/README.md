# EDIFIER 漫步者音响像素屏控制协议与开发套件

本目录包含了对漫步者上位机（EDIFIER TempoHub）逆向分析得出的**像素屏底层通信协议**、**WebHID 网页控制台**以及 **Python 自动化驱动脚本**。

---

## 📁 目录结构

* **`index.html`**：纯前端实现的 **WebHID 全功能像素屏控制台**。在浏览器中直接打开即可直接与漫步者音响 USB 通信，支持像素画板、文字转点阵、麦克风音频律动、实时时钟看板以及滚动弹幕下发。
* **`controller.py`**：Python 版控制驱动与自动化示例（基于 `hidapi`）。
* **`README.md`**：协议文档与接口说明。

## 📦 64 字节数据帧结构 (Frame Format)

上位机向音响发送的每一包 64 字节 HID 报文格式如下：

```
+---------------+---------------+---------------+---------------+---------------+---------------+---------------+---------------+---------------+
| Byte 0        | Byte 1        | Byte 2        | Byte 3        | Byte 4..5     | Byte 6..(5+N) | Byte (6+N)    | Byte (7+N)..63|
+---------------+---------------+---------------+---------------+---------------+---------------+---------------+---------------+---------------+
| Common (0x2F) | Header (0x55) | Device Type   | Command Index | Payload Length| Payload Data  | CRC8 Checksum | 0x00 Padding  |
+---------------+---------------+---------------+---------------+---------------+---------------+---------------+---------------+---------------+
```

* **Byte 0 (Report ID)**：固定 `0x2F`（47）。
* **Byte 1 (Magic Header)**：固定 `0x55`（85）。
* **Byte 2 (Device Type)**：`0x00`（标准 EC 设备）或 `0x01`（ED 扩展设备）。
* **Byte 3 (Command Index)**：命令字低 8 位（`cmd_index & 0xFF`）。
* **Byte 4~5 (Payload Length)**：大端序表示的 Payload 长度（高字节在上，低字节在下）。
* **Byte 6~(5+N) (Payload)**：业务数据载荷。
* **Byte 6+N (CRC8 校验码)**：从 Byte 1 到 Byte 5+N 所有字节累加和取模 256（`sum(frame) & 0xFF`）。
* **末尾填充**：不足 64 字节处全部填充 `0x00`。

## 🕹️ 核心指令集 (Command Set)

| 命令常量 | 命令字 (Hex) | 作用描述 | 说明与 Payload 格式 |
| :--- | :--- | :--- | :--- |
| **`CM_ED02`** | `0xED02` | **屏幕开关与模式设置** | 开屏: `[1, 0, 0]`；关屏: `[1, 0, 1]`；设置模式: `[mode_group, 0, 0, 0, 0]` |
| **`CM_ED03`** | `0xED03` | **256×32 点阵画 / 壁纸分包刷屏** | `[combo_idx, total_pkts, pkt_idx, ...chunk_data]`（单包最多 52 字节数据） |
| **`CM_E8`** | `0x00E8` | **实时滚动文本 / 弹幕下发** | `[source_id, total_text_bytes, ...utf8_bytes]`（分片推送，硬件水平平滑滚动） |
| **`CM_ED1E`** | `0xED1E` | **息屏休眠与屏保设置** | 开启屏保: `[0x02, 0x01, 0x01]`；关闭屏保: `[0x02, 0x01, 0x00]` |

## 🎨 256×32 点阵 BIN 二进制编码算法

### 1. 点阵转字节流 (LSB 垂直分组)
* **屏幕尺寸**：宽 256 列，高 32 行。
* **压缩方式**：垂直方向每 8 行压缩为一个字节，32 行分为 4 个垂直分组（Byte Group 0~3）。
* **数组索引计算**：
  ```python
  group_idx = row // 8       # 0 ~ 3
  bit_offset = row % 8       # 0 ~ 7 (LSB: 第 0 行为最低位 1<<0)
  array_idx = group_idx * 256 + col
  payload[array_idx] |= (1 << bit_offset) if pixel_on else 0
  ```
* **Payload 总大小**：`(32 / 8) * 256 = 1024 字节`。

### 2. 16 字节 BIN 文件头结构
```
[0..7]   : 8 字节 BCD 编码的项目时间戳 ID
[8..11]  : 4 字节大端整数文件总长度 (16 + 1024 = 1040 字节)
[12..13] : Magic 魔数: 0x5A, 0xA5
[14]     : 帧数标识: 0x01 (静态单帧)
[15]     : 保留位: 0x00
[16..]   : 1024 字节像素点阵 Payload
```

### 3. 分包传输 (`CM_ED03`)
* 将 1040 字节文件按每包最多 **52 字节** 切分（共 `ceil(1040 / 52) = 20` 包）。
* 组装分包头：`[combo_index, 20, packet_index, ...52_bytes_data]`。
* 依次发送 20 包，音响校验通过后立即刷屏呈现。

## 🚀 快速测试指南

### 1. 网页直接控制（推荐）
在 **Chrome** 或 **Edge** 浏览器中直接打开 `edifier/index.html`：
1. 点击右上角 **`🔌 连接设备 (WebHID)`**，选择漫步者音响并授权。
2. 在画板上绘制图案或输入文本，点击 **`🚀 刷入屏幕`**。
3. 支持切换至 **“实时音频律动”** 或 **“智能时钟”** 选项卡体验动态效果。

### 2. Python 自动化脚本
安装依赖并运行测试：
```bash
pip install hidapi
python edifier/controller.py
```
